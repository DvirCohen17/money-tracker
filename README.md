# MoneyTracker v1.2.0

גרסת UX וחשבון חדשה הכוללת:
- ערכות עיצוב מלאות לרקע, כרטיסים, כפתורים וצבעי הדגשה
- חלונית הודעות עליונה עם 3 הודעות אחרונות + מרכז הודעות מלא
- סימון הודעות כנקראו וניווט ישיר לניתוחים
- מסך פרופיל נפרד ומשתמשים מופרדים
- מסך פתיחה להתחברות/יצירת משתמש
- תמיכה בחשבונות מרוחקים דרך API + שמירת state ב-DB
- מצב מקומי/offline כאשר אין API מוגדר
- Heatmap חודשי מפורט ו-Heatmap היסטורי גדול יותר
- PWA עם התקנה כאפליקציה
- אבטחה בסיסמה ונעילה אוטומטית

## חיבור לשרת

ברירת המחדל היא עבודה מקומית. כדי להפעיל משתמשים ומסד נתונים מרוחקים, הגדירו את `window.MONEYTRACKER_API_URL` בקובץ `config.js` או ב-localStorage תחת `moneytracker_api_url`. השרת כולל API להתחברות, יצירת משתמש, טעינת state ושמירת state.
